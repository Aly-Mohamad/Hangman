## Overview
Hangman is a classic word-guessing game implemented in **Java**. Players try to guess a hidden word by suggesting letters. Incorrect guesses add to the hangman drawing. The game ends when the word is guessed or the hangman is fully drawn.

This project includes both the **Java source code** and a **Windows executable (`.exe`)** for easy play.

---

## Features
- Interactive GUI with hangman drawing
- Case-insensitive letter input
- Ready-to-run `.exe` for Windows
- Fun and educational game

---

## Files in This Project
- `Hangman.java` — Main source code  
- `HangmanGUI.java`, `HangmanPanel.java` — GUI classes  
- `Hangman.exe` — Windows executable  
- `README.md` — Project documentation

2. Double-click `Hangman.exe` to launch the game.
